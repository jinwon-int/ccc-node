- **self-update: a restart handed to a detached follower is a deferral, not a failure (#2626).** On Termux the restart command (`termux-restart-frontends.sh`) leaves a busy Matrix/hande frontend to a detached follower and exits 0 — correct — but self-update's 60 s health wait then saw the old generation and recorded `external-restart-failed` (exit 7, owner alarm, pending record kept as "failed" until the next tick) although the follower activated the new generation minutes later (gongyung, 2026-11-01). The restart script now keeps a hand-off ledger (`CCC_SELF_UPDATE_RESTART_DEFERRED_FILE`, default `~/.claude/state/self-update.restart-deferred`: `<epoch> pending <frontend> want=<gen> max_wait=<s>`, followers append `… done <frontend> rc=<n>`), self-update clears it before each run and passes the path to the command; a health-timeout with a frontend still pending there is recorded as `external-restart-deferred` (exit 14, audit `activation-deferred`, one calm owner notice naming the frontend and its wait) and the existing next-tick reconcile clears it once the serving generation matches. A follower that already finished unhealthy stays a real failure (7).
