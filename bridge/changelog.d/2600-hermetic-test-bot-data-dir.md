- **The bridge test suite no longer writes runtime state into the checkout (#2600).** `tests/conftest.py` pins `PROJECT_ROOT` to the bridge checkout, so with `BOT_DATA_DIR` unset the global health reporter and task ledger wrote `health.json`, `tasks.json` and `tasks.json.bak` into `<checkout>/bridge/.telegram_bot` — the live bridge's own files on a node that runs the bridge from that checkout, and a file shared by every pytest-xdist worker. Each test process now gets a private `BOT_DATA_DIR` (a `mkdtemp`, removed at exit) that `_reset_bridge_environment` re-applies around every test; tests that exercise `BOT_DATA_DIR` parsing still set or delete it themselves. `tests/test_hermetic_bot_data_dir.py` guards that `bot_data_dir`, `logs_dir`, `session_store_path` and the ledger/health paths resolve outside the checkout.
