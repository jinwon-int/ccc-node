- The 「한데」 (`CCC_CHANNEL=hande`) bridge now runs self-jobs like the Matrix frontend (#2561). `HandeTransport` had no `enqueue_self_job`, so the CI-wait resume (the "continue once CI is green" turn), yield-and-continue bundles and the Danso auto-resume were all deferred as "no transport/room" and never ran. Self-jobs now run while the native bot is connected and between bot turns, with the Matrix admission rules (owner by default; a family user only in a family room) and idempotent per key; their reply, progress lines and any refused approval go out as `notice` frames. A bot turn that arrives meanwhile is held instead of `rejected` (which would end the owner's message as `uncertain`), and a held `/stop` or `/cancel` cancels the self-job. Not-yet-started jobs persist in `bot_data_dir/hande-self-jobs.json` (0600) and leave it when they start, so a restart never runs one twice. Self-jobs are refused while `notice_frames` is off — that switch also gates CI-wait results and background-task completion notices, which every hande node dropped (`hande notice dropped`) while it stayed at its `false` default; set `"notice_frames": true` in `/etc/ccc-hande/config.json` on nodes whose `native-mls-bot` speaks the frame (#474) and restart `ccc-hande-bridge` at idle.
