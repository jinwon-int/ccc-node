- Tests: the 3.12 full-suite failure of `test_terminal_stall_preserves_interrupt_cancel_abort_close_order` (#2349) is fixed. The terminal-stall grace (0.05 s in the test) counts from the first text event, so on a loaded runner applying that event used up the bound before the next read was scheduled; `_read_bounded_event` then correctly took its expired-bound branch (interrupt → abort, no read to cancel) and the assertion, which expects a pending read, saw `['interrupt', 'abort', 'aclose']`. The observed `Event loop is closed` was an unrelated unraisable warning from `test_danso_runtime`. A new `_pin_terminal_stall_bound` helper fixes the selected TERMINAL_STALL bound so each test exercises one branch deterministically: the order test and `test_cancellation_during_interrupt_reaps_read_before_iterator_close` (same latent assumption) pin 0.05 s, and a new `test_expired_terminal_stall_bound_interrupts_and_aborts_without_a_read` pins 0.0 to cover the no-read branch. No production code changed.
