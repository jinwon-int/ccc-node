- Main-session model parity between a node's bridges (#2576): the model a Claude conversation runs on without a `/model` choice is now resolved the way the CLI does — `ANTHROPIC_MODEL` (the unit's main-session env) first, then `~/.claude/settings.json` — in the `/model` table, the `/new` session-model sync (Matrix and Telegram) and the session-start banner. Before, settings.json alone was read, so a bridge whose unit env and settings disagreed showed and persisted one model while its turns ran on another. The banner also prints the operator label (`CCC_MODEL_LABEL`) for a persisted model that merely restates the env-routed one, so the Matrix and hande bridges of one node print the same `◆ Model:` line for the same backend.
