- **Push spool: a record can name one of the bridge's own rooms (#2829).** A local writer (cron job, script) may add `"room": "<room id>"` to a spool record. When that room is in the transport's configured rooms (`policy.rooms`), the record is posted there as plain text (no `🔔 ccc-node [event]` header) — in relay mode too, where it takes the direct-event path instead of the fleet room. A room the bridge does not serve falls back to the normal route (owner room), so a record can never open a new destination; records without `room` are unchanged. `pending_count(relay_only=True)` no longer counts such records as relay-bound. For a 「한데」 alert room the node also needs the room in the bridge `rooms` list and `NATIVE_MLS_BOT_ROOM_FRAMES=1` on the bot.
