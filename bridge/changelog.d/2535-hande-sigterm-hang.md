- The 「한데」 (`CCC_CHANNEL=hande`) bridge now exits on SIGTERM while the native bot is still connected (#2535). `HandeTransport.run()` used `async with server`, whose exit awaits `Server.wait_closed()` without a bound — and from Python 3.12 that waits for every open connection, which the native bot never closes on its own. The cancelled serving task therefore never reached the `close()` that hangs up: every systemd stop ran into the 70 s `TimeoutStopSec` and was SIGKILLed (resident `claude` children included), and under Termux runit the unit stayed in `got TERM` indefinitely with health `degraded`. `run()` now closes the transport in its `finally` (client first, bounded server wait), and `close()` is idempotent and cancel-safe so `MatrixBot.serve`'s own `close()` joins the same shutdown.
