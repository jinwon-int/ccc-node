- Every completed tool call in a Claude bridge turn now also appends one body-free `tool` span to `.telegram_bot/spans/YYYY-MM-DD.jsonl` (`gen_ai.operation.name=execute_tool`, `gen_ai.tool.name`, hashed `gen_ai.conversation.id`, `ccc.tool.scope` main|subagent, `start_ts`, bridge-observed `duration_ms`, `status` ok|error with `error.type=tool_error`). Spans are derived in-process from the SDK frame stream by pairing `ToolUseBlock`/`ToolResultBlock` ids — no `PostToolUse` hook, no settings change. Tool input, output, paths, command text and raw call ids are never stored; at most 256 calls are tracked in flight, unmatched calls are dropped at turn end or session reset, and every failure is swallowed. Same `CCC_SPAN_LEDGER_ENABLED` / `CCC_USAGE_METER_ENABLED` switches (`core/tool_spans.py`, #2684 slice 2).
