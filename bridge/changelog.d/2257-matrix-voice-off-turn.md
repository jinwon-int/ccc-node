- Matrix voice replies (`MATRIX_VOICE_REPLY`) are now synthesized in a background task after the turn, so the finished text answer is no longer held back for up to 120 seconds. When synthesis ends, the speech is filed by the parent turn's state in one store transaction: queued behind a recorded answer, held for a still-running turn, or discarded with its file when the turn was stopped, timed out or failed, so no held file is orphaned behind an already-finished turn. `/stop` in the room and bridge shutdown cancel in-flight synthesis and remove its temporary files; synthesis failures only log. The default stays off pending re-review.
- Voice delivery strategy: replies with more than 2000 Hangul syllables stay text-only, matching the existing English-word limit by spoken length (applies to Telegram voice replies too).
