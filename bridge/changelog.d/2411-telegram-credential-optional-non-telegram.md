- `TELEGRAM_BOT_TOKEN` is now required only for the Telegram frontend (`CCC_CHANNEL` unset/`telegram`) (#2411). `CCC_CHANNEL=matrix`/`hande` settings load without it, and a blank or placeholder value (`your_bot_token_here`) counts as absent (`telegram_bot_token` is `None`). The Telegram channel still refuses a missing token with the same `TELEGRAM_BOT_TOKEN is not configured` message, which now also covers a key that is missing entirely instead of pydantic's bare `Field required`. The Telegram-only consumers (PTB application build, voice/file download URL) refuse a missing token explicitly instead of building a `botNone` URL; the Grok-on-Matrix route still requires the token as its journal identity label (`grok_telegram_identity_mismatch`). The process env > project `.env` > package `.env` precedence and its placeholder fallback are unchanged.
