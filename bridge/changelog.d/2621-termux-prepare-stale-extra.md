- **termux-prepare: a ready generation built without the Matrix extra no longer wedges the node (#2621).** On a Matrix-frontend Termux node one tick's `--extra` probe (`git show <target>:bridge/termux_prepare.py`) failed transiently, so an extra-less generation was built and refused at the promotion gate — correct — but every later tick re-found that "ready" generation on the repoint path, refused it again and never rebuilt; the node stayed on the old generation until an operator deleted the directory (daegyo, 2026-11-01). `termux-prepare-generation.sh` now skips a ready generation that fails `matrix_extra_present` (kept on disk for diagnosis) and builds a fresh one with `--extra matrix`, and the probe distinguishes a failed `git show` (retried once after 2 s, then exit 3 with the pointer unchanged) from a tool that genuinely lacks `--extra`.
