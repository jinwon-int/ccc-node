- **External-wait switches honour the bridge `.env`; resume cap default 10 → 30 (#2841).** `ExternalWaitMonitor.env_int` / `env_flag` read only `os.environ`, and the Hande / Matrix entry points (systemd unit, `env -i` Termux wrapper) never pass through `start.sh`'s `.env` export, so values such as `CCC_EXTERNAL_WAIT_RESUME_DAILY_CAP` written to `.env` were silently ignored. `Config.load` now keeps the non-credential `CCC_*` keys of the two `.env` layers (project over package fallback, process values excluded) and `python -m telegram_bot` installs them into `utils/dotenv_fallback`; the helpers consult them only when the process environment lacks the key, so precedence matches every other setting and nothing is exported to child processes. The default daily auto-resume cap rises to 30: at 10 it was exhausted on most nodes by ordinary PR traffic (one PR registers CI, actions-run and merge-queue waits), while nodes already pinned at 30 never reached it.
