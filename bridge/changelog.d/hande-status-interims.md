- **hande: `status_interims` forwards the `⏳ Working — Ns | <tool>` heartbeat as throttled interim frames.** Matrix edits one status bubble in place every 10 s; the hande port has no editable bubble, so `TurnSink.status` was a no-op and a long turn looked silent in 「한데」. With `status_interims: true` (default off; needs `interim_frames`) the heartbeat goes out as an `interim` frame — a new room message each time — throttled to the first line when the heartbeat starts, then only on a tool-label change or after `status_interim_interval_s` (default 60, 10..3600). `None` (clear) sends nothing, answer previews (`🔧 …`/`… ▍`) are never forwarded, and with `interim_frames` off the line is counted in `notices_dropped`. `health_signals()` reports `status_interims`. An in-place status bubble needs an app-layer `status` message kind on the family-messenger side (tracked with the live-preview gap).
