- **Turn span output tokens match the cost ledger (#2684 slice 4).** `turn_span_from_claude_result` now sums per-model `output_tokens` whenever model rows exist, like input tokens and the cost ledger, and uses the SDK's top-level `usage.output_tokens` only as a fallback. The top-level value left out auxiliary/subagent models and, not being session-cumulative, its per-turn delta collapsed to 0 on later turns of a session: on one node on 2026-11-07 six turns recorded 51,279 output tokens in spans against 137,598 in the ledger (−62.7 %); with the fix every turn matches the ledger row. New regression tests cover the auxiliary-model and second-turn cases.
