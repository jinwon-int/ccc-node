- **feat(bridge): show the skills an agent uses (#2833).** The `⏳ Working` status line (Telegram, Matrix, and the hande status-v1 bubble) names a loaded skill as `📘 <name>` instead of `Skill` or `Read: …/SKILL.md`. The new `core/skill_display.py` detects a skill from a `Skill` call or a `Read` of `…/skills/[.system/]<name>/SKILL.md`, the same two paths the `skill-usage-log.sh` ledger counts. It returns identifier-shaped names only, never arguments or paths. `TurnEventState` keeps the turn's skills (first-seen order, at most 8). `ChatResponse.skills` and `TurnResult.skills` (default `()`) carry them to the transport. With the new hande knob `skill_frames: true` (default off), a `complete` `result` frame carries `skills: [...]`, which family-messenger#834 draws as chips under the answer. With the knob off, frames are unchanged. `health_signals()` adds `skill_frames` and `skill_results`.
