- readable renderer: list spacing renders the same on telegramify-markdown 1.2.x and 1.3.0+. 1.3.0 stopped eating the blank line after a list ("Blocks after a list keep their blank line"), so the gap filler that compensated for it doubled list gaps (items 1 → 2 blank lines, list end → next block 2 → 3) and failed `test_tg_md`/`test_tg_entities` on the weekly lock PR #2279. Between two list items the gap is now filler lines without a real blank (renders `spacing - 1` on every version); after a list the filler count follows the installed telegramify version (`converter_keeps_list_blank`, `importlib.metadata`), so a node whose venv lags its checkout keeps uniform spacing (#2280).
