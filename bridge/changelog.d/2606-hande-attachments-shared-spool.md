- 「한데」 inbound attachments (#2606) now also work where the native bot and the bridge run as different users (the Linux systemd nodes: bot as `native-relay-bot`, bridge as root or as a member of the bot's group). The bridge still takes the spool file over with a `rename` and verifies it, but it now trusts a file owned by the **spool directory's owner** as well as its own uid, and accepts mode 0600 or 0640 (group-readable for a non-root bridge). A spool directory writable by "other" is refused, so only the bot and its group can place files there. Termux nodes (one uid, 0600) are unchanged.
