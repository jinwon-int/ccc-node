- **fix(agent-cron): a node without a time zone database no longer calls a valid zone a typo (#2815).** On Termux nodes Python has no IANA database (no OS zoneinfo, no `tzdata` package), so `agent-cron.sh add --timezone Asia/Seoul` — the documented example — failed with `unknown timezone: Asia/Seoul`; a 10-minute watchdog registration was rolled back that way. `resolve_timezone()` now probes the database when a name is not found and says `no time zone database on this node (cannot resolve <name>): install the Python tzdata package … or use UTC`; a wrong name on a node that has a database is still `unknown timezone: <name>`, and both stay fail-closed. `ccc-doctor` gains a non-fatal `timezone database` row from the same probe, and `docs/agent-cron.md` documents the UTC workaround. No node is changed by this: installing `tzdata` remains an operator step.
