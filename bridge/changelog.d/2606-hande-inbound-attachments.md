- The 「한데」 (`CCC_CHANNEL=hande`) bridge can now take inbound photos and documents (#2606), following the frame contract in family-messenger `docs/FLEET-WORKER.md` ("첨부 turn — `attachment`", #637). The native bot decrypts the file-v2/v1 attachment itself, so the per-file key never reaches the bridge, and names the plaintext spool file in a new optional `turn.attachment` object. With the new `attachment_frames` knob on (default `false`) and `attachment_spool_dir` set to the bot's spool path, the bridge validates the object (a malformed one is `rejected` with `invalid-attachment`) and takes the file over by renaming it into `BOT_DATA_DIR/matrix-media`. There it checks regular file, same uid, mode 0600, size, sha256 and the Matrix size limits, then runs the Telegram/Matrix image or document prompt labelled `Hande` and deletes the file when the turn ends; a failed check answers once with the Matrix attachment wording. With the knob off, or for an unknown frame version, the turn runs on its `prompt` as before. `MatrixBot._attachment_prompt` gained a `channel` keyword (Matrix default unchanged). Nothing changes on a node until both this knob and the bot's own attachment switch are on, in that order.
