- The turn-stall probe can now confirm a dead Claude SDK session when its CLI subprocess has exited, not only when the reader task has already observed the stream end (#2443): `ClaudeTurnLiveness.engine_verdict` reads the subprocess exit code through the same guarded private-attribute path the transport diagnostics use (`sdk_process_exit_code`, shared), so dead-session recovery runs instead of logging `liveness unknown` forever. A silent turn on a running process still reports "unknown" and is never recovered on a guess; that log line now carries the silence length, which liveness arm judged it, and that `/stop` is the manual release, and every unknown verdict is counted in health as `stall_probe_unknown_recent` (last hour, count only — a long-running tool produces the same shape, so no alert).
