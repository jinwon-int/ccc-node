- **`health.json` is published through a uniquely named temp file (#2598).** `RuntimeHealthReporter` wrote every snapshot via the fixed `health.json.tmp`, so two writers on one data dir could rename each other's temp away and fail with `FileNotFoundError` (seen as a flaky `test_connection_resilience` failure once the bridge suite ran under pytest-xdist). It now writes a `mkstemp` temp in the same directory and `os.replace`s it, as the task ledger and matrix lifecycle already do; the published file keeps its previous mode (`0o666 & ~umask`) and a failed write leaves no temp behind. Regression test: four reporters × 200 concurrent writes on one data dir.
