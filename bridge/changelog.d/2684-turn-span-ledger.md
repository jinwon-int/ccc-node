- Each terminal Claude turn now also appends one body-free `turn` span to `.telegram_bot/spans/YYYY-MM-DD.jsonl` (UTC day) using OpenTelemetry GenAI attribute names (`gen_ai.request.model`, `gen_ai.usage.input_tokens`/`output_tokens`, hashed `gen_ai.conversation.id`) plus `ccc.node`/`ccc.channel`/`ccc.turn_id`/`ccc.outcome`, `duration_ms` and `status`. Keys are allowlisted, strings must be identifier-shaped, capped and redacted, so no prompt/tool/answer text is stored; writes are one `O_APPEND` line in owner-only files and every failure is swallowed. Day files older than `CCC_SPAN_RETENTION_DAYS` (default 14) are pruned at most once per UTC day; `CCC_SPAN_LEDGER_ENABLED=false` (or `CCC_USAGE_METER_ENABLED=false`) turns it off (`core/span_ledger.py`, #2684 slice 1).
