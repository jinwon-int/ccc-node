- `SessionRequest.mcp_allowed_tools` (#2345): a caller may pre-approve tools of its *own* `mcp_servers` (`mcp__<server>__<tool>`, server must be one of the request's servers) so they run without the per-call approval round trip; built-in tools and other bundles' tools are rejected at validation. The Claude adapter passes the list as the caller bundle's `allowed_tools`. First consumer: family-messenger's read-only steward tools (`room_status`, `room_members`; jinwon-int/family-messenger#378). Requests without the field are unchanged.
