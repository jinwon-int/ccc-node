# skill-router synonym map (ccc-node #2645, #2748) — `surface => english tokens`.
#
# Skill descriptions are English; operator prompts are mostly Korean. Lines
# starting with # are comments. One concept per line; order does not matter.
#
# How a surface matches (lib/skill_router.py, surface_matches):
#   - ASCII surface: a whole token ("pr" is not inside "provider").
#   - Korean surface of 1-2 syllables: only at the start of a word; particles
#     and endings may follow ("머지해줘"), another word may not precede
#     ("나머지" is not "머지").
#   - longer Korean surface: anywhere (compounds written without spaces).
#
# What to put on the right (#2748 — the table was the largest source of wrong
# suggestions):
#   - translations and near-synonyms of the surface only. All targets of one
#     line count as ONE shared concept, so listing several costs nothing and
#     earns nothing: a line can never satisfy a match by itself.
#   - no domain leap: never map a common word onto a product or a skill
#     family it does not name ("문제" is not NCLEX, "브리지" is not Telegram,
#     "승인" is not review). A leap hands the router evidence the operator
#     never gave.
#   - no surface that is mostly something else in everyday Korean ("문제",
#     "체크", "키", "감사"): spell out the specific phrase instead.
#   - keep targets to words that actually appear in skill descriptions.
