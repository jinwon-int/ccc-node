# Skill-listing core set (ccc-node#2011 A) — one skill name per line.
#
# Claude Code injects the skill listing each turn under a character budget
# (`skillListingBudgetFraction`, default 1% of the context window). Over the
# budget it keeps every name but only describes the most-used skills, so on a
# node with ~200 skills most of them — including the fleet workflows below —
# were listed as bare names. scripts/ccc-skill-listing-policy.py keeps the
# description for every skill named here plus recently used skills while they
# fit the budget, and sets the rest to `skillOverrides: "name-only"` (still
# listed and invocable; never "off", never deleted).
#
# Keep this list short: every entry spends listing budget on every turn of
# every session, before any recently used skill gets a description (#2031).
# Keep each core description short too: "Use when ..." first, <=300 chars.
# Names absent on a node are ignored. Custom commands under ~/.claude/commands
# (wiki-log, a2a-claim, doctor, ...) are not managed by the policy at all, so
# they do not need an entry here.
