- **erasure planner: operator scratch that is not owner-only is kept, not planned for deletion (#1468, owner decision 2026-10-23 option 2).** `ccc-erasure-apply.py` refuses an entire run when any target is not owned by the effective uid or carries a group/other permission bit, and 24 of 45 scratch files on the first node measured were `0644`/`0755` — so every prune-expired run there would have been refused, and fixing the bits with `chmod` would have restarted the 90-day clock (ctime). The planner now applies the same owner-only test to the `state.operator_scratch` fallback and plans such files as `retain (not owner-only)`; rule order is live claims → key file → symlink → owner-only → scheduler guard → age. Named retention classes (group a/b) are unchanged.
