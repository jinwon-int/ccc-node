- **Skill promotion: collect from a lane owned by a different remote account, and report outboxes nobody collects (#2153).** Collect entries now accept `identity=alias`. `export` and `ack` dial `alias`, while the envelope node is still checked against `identity` (#1067 guard unchanged), so a lane that moved to another remote user no longer needs the identity alias re-pointed. `run` and `status` report `outbox: {pending, oldest_created_at, stale}`, where `stale` means a servable envelope has gone uncollected longer than `CCC_SKILL_PROMOTION_OUTBOX_STALE_HOURS` (default 72). The autosave sweep logs a dedicated `promotion-outbox-stale` line. Previously a collector reading the wrong account returned `ok` with zero envelopes, and an unserved backlog sat for weeks with no signal.
