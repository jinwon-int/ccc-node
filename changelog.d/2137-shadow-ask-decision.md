- **gh-pr-flow:** the delegated-approval shadow recorder can now record that the owner was *asked* (`ask`) and a person's non-approval (`decide`: `decline`, `hold`, `closed-unmerged`), so a refused L1 becomes countable (#2137, spec §10.2 5-d). How each ask ended is derived in `summary`, which also takes a fixed window (`--since/--until`) and several ledgers (`--ledger`). Record-only: approvals behave as before, no text is stored, and `CCC_DELEGATED_SHADOW=0` still turns it off. Ledger rows are schema v2; v1 rows read as approvals.
