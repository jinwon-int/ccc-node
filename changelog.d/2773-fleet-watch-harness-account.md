- **fleet-watch: a retired node whose harness belongs to a non-root service account can now be doctor-checked (#2773).** The doctor sweep probes as root, so such a node reported `RETIRED … doctor:unverified-harness` every day: nothing was inspected and nothing paged (seen on the 2026-11-07 and 11-12 sweeps after #2704). `CCC_FLEET_HARNESS_ACCOUNTS="<node>=<account>"` names the account; its home, `self-update.repo` and `~/.claude` replace the probing login's, and the doctor and memory check run as that account. If a declared account cannot be inspected, the result is `UNVERIFIED <node> inspection=harness-account:<reason>`. A malformed declaration fails the run before any probe. The install-reference metadata check now treats group write as owner write only when the group can hold no account but the file's owner (a umask-002 account's user-private group). Other-write, shared groups and unknown groups are still refused, and Android, which has no `grp` module, keeps the old rule. Undeclared nodes are unchanged.
