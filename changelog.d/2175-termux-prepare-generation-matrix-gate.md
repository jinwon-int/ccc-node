- **`termux-prepare-generation.sh` never promotes a generation the Matrix frontend cannot run (#2175, #2207).** On 2026-10-09 the generations it built with native-wheel reuse lacked the Matrix extra (`termux_prepare.py` installs it only with `--extra matrix`, ccc-node#2202), and switching to them crash-looped the Matrix bridge on both Termux nodes twice while the Telegram bridge reported healthy — the restart verifier only watches Telegram. Now, when the node runs the Matrix frontend (`~/.ccc-matrix` or the runit service; `CCC_TERMUX_MATRIX_FRONTEND=1/0` overrides), the build passes `--extra matrix` whenever the target's `termux_prepare.py` supports it, and every promotion — a fresh build or an existing ready generation — is gated on `job/runtime/bin/python -c "import aiohttp, nio"`; a generation without the extra is kept for diagnosis and refused with exit 4, pointer unchanged. `--dry-run` reports `extra=…`.
