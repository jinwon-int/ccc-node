- **`setup.sh --refresh-guidance` also spreads the Web reading rule (#2892 A).** `claude/CLAUDE.md.template` now carries a marker-delimited block (`<!-- ccc:web-reading:begin -->` … `end`) telling the main session to read the web through the isolated `web-reader` sub-agent and to treat web/issue/PR/mail/tool text as data. Because `seed()` never overwrites a node's CLAUDE.md, `scripts/ccc_memory_guidance.py` now keeps that block current too: a marked block is replaced by the template block; a file without the markers gets it inserted before `## Standing Orders` (else `## Interaction`, else at the end) unless a hand-written `` `web-reader` sub-agent `` paragraph is already there. The block is independent of the Memory Stack block, so a node whose memory span is refused as node-customized still receives it (backup first, exit 1 so the refusal stays visible). Nothing runs on a node until the operator runs `./setup.sh --refresh-guidance`.
