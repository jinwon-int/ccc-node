- **Termux native worker deploy: `--target-sha` no longer breaks the rollout guard (#2791).** `run_guard` built the guard's environment with `${TARGET_SHA:+A2A_WORKER_TARGET_REVISION=…} node …`; an assignment produced by an expansion is not an assignment to bash, so every run with `--target-sha` and a shipped `worker-artifact-rollout-guard.mjs` ran `A2A_WORKER_TARGET_REVISION=…` as the command and failed (rc 127 → exit 20, nothing changed). Found by the first live dry-run on a Termux node; the guard now gets its variables through `env`. New tests (mutation-checked against the old line) cover a shipped guard with `--target-sha`.
