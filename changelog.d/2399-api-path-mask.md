- **Skill promotion no longer voids a valid revision because a `gh api` REST path looks like a token (#2399).** The `possible-token` re-gate (`[A-Za-z0-9+/]{40,}`) now also masks scheme-less slash paths with two or more slashes whose every segment is shorter than 40 characters and reads as a word (lowercase or Capitalised word, letters-only caps placeholder such as `OWNER`, number) — e.g. `repos/OWNER/REPO/actions/runners/registration-token`. A run with any non-word segment (a random base64 secret mixes cases and digits), a `+`, or a `scheme://` URL is never masked, so #2371's rule that general URLs stay scanned holds. A `secret_*` re-gating failure now records each match's file, line and length (never the value) in the ledger row and the PR comment.
