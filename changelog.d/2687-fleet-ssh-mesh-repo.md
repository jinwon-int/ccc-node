- **`scripts/fleet-ssh-mesh.sh`: fleet SSH mesh provisioning in the repo, with an external node table (#2687, proposals 1–2).** The per-node-key full-mesh script (`collect|scan|build|push|verify`) now lives in `scripts/` with a hermetic test suite. The node list moves out of the script into `${CCC_FLEET_SSH_NODES:-~/.config/ccc/fleet-ssh-nodes}` (`name port user [host]`; `--nodes FILE` overrides); a node without `host` is resolved from `tailscale status --json` at run time, and a missing, ambiguous or malformed entry stops the run before any remote action. Same managed-block markers as the earlier copy, so deployed blocks are replaced, not duplicated. New: `push --dry-run`, backups that are never overwritten, refusal to rewrite a file with unbalanced markers, `build` refusing a partial collect/scan unless `--allow-partial`, non-zero exits on node failures. Private keys still never leave their node. Docs: `docs/fleet-ssh-mesh.md`.
