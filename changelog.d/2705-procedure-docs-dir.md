- **Merged worker-procedure docs no longer wait for a broker deploy to reach reviewers (#2705, owner decision A).** New opt-in `CCC_SKILL_PROMOTION_PROCEDURE_DOCS_DIR`: the review and revise worker procedures (`docs/skills-intake-review.md`, `docs/skills-intake-revise.md`) are read from that a2a-nexus clone instead of `CCC_SKILL_PROMOTION_A2A_NEXUS_DIR`, while `scripts/a2a-dispatch-round.mjs` stays on the broker checkout. Unset, nothing changes. Each live collect fast-forwards the clone first (`fetch` + `merge --ff-only @{u}`); a missing repo, failed fetch, dirty tree or non-fast-forward keeps the previous tree, never blocks the collect, and writes one deduplicated `a2a-procedure-docs` ledger row (`docs_not_git`/`docs_fetch_failed`/`docs_dirty`/`docs_not_ff`; a head change writes `updated`). With the clone set, a review procedure whose `Rubric version:` mark differs from `_INTAKE_RUBRIC_VERSION` is refused as `dispatch_docs_rubric_mismatch`. Every `a2a-dispatch` and `a2a-revise-dispatch` row now records `procedure_doc`, `procedure_sha256` (16 hex), `procedure_source` and, for a git checkout, `procedure_commit`.
