- **Two PostToolUse reminder hooks from the harness-design study (arXiv 2609.20804 §2.4, #2261).** `post-edit-lint.sh` runs right after an `Edit`/`Write`/`MultiEdit` of a `.py` file: `ruff check --select E,F` (override `CCC_POST_EDIT_LINT_RUFF`; PATH, repo venvs, `~/.local/bin`), falling back to `python3 -m py_compile` when ruff is absent, and returns findings as `additionalContext` so syntax errors, undefined names and unused imports are seen before the test turn instead of in CI. Repo-scoped by default (`CCC_POST_EDIT_LINT_SCOPE=all` widens), 5 s timeout, 2 KiB cap with the finding count kept, body-free count log in `$CCC_STATE_DIR/post-edit-lint.log`; `CCC_POST_EDIT_LINT=0` disables. `tool-streak.sh` counts consecutive identical calls (same tool, byte-identical `tool_input`; `Read` excluded) per session and warns once per streak at `CCC_TOOL_STREAK_LIMIT` (default 3) — the Claude lane's counterpart of Danso `CCC_DANSO_TASK_REPEAT_LIMIT`; state holds hashes and counters only, `CCC_TOOL_STREAK=0` disables. Both are reminders, never gates (always exit 0), registered in `hooks/hooks.json` and `enforcement-overlay.json`, with hermetic `*.test.sh` suites.
