- **A2A Terminal Brief → Matrix fleet alerts** (#2498, a2a-nexus#2460): new `scripts/a2a-terminal-brief-fleet-notify.py` and systemd service/timer examples. The OpenClaw Gateway notifier that consumed the broker terminal outbox retired on 2026-08-09, and nothing has consumed the outbox since. This script fills that gap: on a broker host it reads the local outbox by cursor and drops one push-spool record (`event: A2ATerminalBrief`) per new operator-facing row into the "🔔 플릿 알림" room. It also records receipt `produced` on the broker row, which is not an ACK. The first run pins the cursor at the end of the outbox, so the backlog is never sent. A row created before the first run is never sent even when an aged-out cursor makes the broker replay the outbox from the start.
