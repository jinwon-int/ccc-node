- bridge: the session resource guard no longer evicts a session whose Claude CLI is mid autonomous turn or still owns run-in-background tasks. The registry marks only bridge-submitted turns active. A turn that Claude Code starts by itself after a `<task-notification>` therefore looked idle, and on a small host the tree-RSS branch (`rss ≥ limit && active_sessions == 0`) closed the session and SIGKILLed the running tool (field case: `wiki-agent pr` exited 137 six seconds in on a 4 GiB node whose idle tree already sat at ~1015 MiB against the 1024 MiB floor). Claude sessions now expose `autonomous_turn_inflight()`. The guard peeks each idle candidate and skips it while that seam, or `background_workload_snapshot()`, reports work; a failing probe counts as busy. The Codex runtime recycle waits the same way. Skips are counted as `busy_deferrals` in the resource snapshot and logged only when the count changes (#2291).
