- **fix(memory): hook-path resumes carry their capture time, and a rollback no longer rewrites unchanged memory files (#2310).** The node-global bridge sink ordered a hook-written (header-less) `resume.md` by its file mtime — when extraction finished, not when the CLI session was captured — so a bridge capture taken in between was wrongly kept out. `local-memory-commit.py` now stamps the same `<!-- ccc-node:distill captured_at=… provider=claude -->` header the bridge sink reads, using the pending job's `created_at` (the moment the hook pinned the transcript), passed to the re-entered `distill.sh` as `CLAUDE_DISTILL_CAPTURED_AT`; a `pending-drain.sh` replay of an old backlog keeps that original time. Runs outside the pending journal stay header-less (mtime ordering, as before). `LocalMemoryTransaction` rollback and crash-recovery abort now restore only targets that differ from their pre-image, so a facts-only rollback no longer bumps `resume.md`'s mtime.
