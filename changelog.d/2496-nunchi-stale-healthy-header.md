- **nunchi no longer prints "⟳ 합성 상태 재확인 필요" when the last synthesis record was healthy (#2496).** The weekly bench is usually the only synthesis caller while the backend-health cutoff is 24h, so a healthy node read `stale` about six days in seven and every session header carried the recheck line, diluting the real `degraded`/`outage` warnings. `backend_health_state()` and `nunchi.py backend-status` are unchanged (still `state: stale`); the session header drops the ⟳ line only when the aged window would have read `ok` — the last call answered by its primary and fallbacks under the degraded bar. An aged fallback, outage or degraded window keeps the line, as #2129 intended.
