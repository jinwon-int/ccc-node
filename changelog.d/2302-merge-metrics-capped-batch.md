- **fleet-metrics: the effective merge-queue batch is no longer overstated when `/actions/runs` hits its 1,000-run cap (#2302).** Groups were counted only from the capped run list while the numerator counted every PR merged in `--days`, so a 30-day ccc-node run read 2.05 against ≈0.95 measured on an uncapped window. When the run list is capped, `fleet_merge_metrics.py` now divides only the PRs merged since the oldest fetched run, marks the value `*` in the table and records the window in `batch_since` / `batch_merged_prs`. `docs/fleet-merge-metrics.md` records the #2302 verdict: batching reverted on 2026-11-13.
