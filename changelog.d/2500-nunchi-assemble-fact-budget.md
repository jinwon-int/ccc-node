- **nunchi `assemble` no longer charges the constraint block against the fact budget (#2500).** Since #2216 the constraint block has its own byte budget (`CCC_NUNCHI_CONSTRAINT_BUDGET`, default 12000), but `assemble` still subtracted those bytes from `--budget` (`CCC_NUNCHI_ASSEMBLE_BUDGET`, default 3000) before filling facts. On every measured node the constraint block alone exceeded 3000 B, so the SessionStart fact block shrank to the one guaranteed line and the auto-distill share computed to 0 bytes — 1,531 injected sessions on 7 opt-in nodes carried no `·auto` line (2026-10-09..10-24, #2186). The fact budget is now charged for the header only; the 33% auto-distill share is taken of that block. `ccc doctor`'s always-on estimate for the nunchi row is now `assemble + constraint` (15000 B by default) instead of `max(...)`.
