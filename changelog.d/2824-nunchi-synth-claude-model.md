- **nunchi: the claude synthesis model is configurable and recorded in the bench summary (#2824).** `_synth_candidates()` hardcoded `--model haiku`, a Claude Code CLI alias whose target moves with CLI updates (2026-11-16 yukson: `claude-haiku-5-5` on CLI 2.1.322), and `bench-*.md` recorded neither the model nor the CLI, so the 11-09 → 11-16 Wiki-layer shift (#2823) could not be separated from a model swap. `NUNCHI_SYNTH_CLAUDE_MODEL` now sets it; the default stays the `haiku` alias, because a pinned id breaks silently (synthesis falls through to codex) once that model is retired — pinning is a per-node choice. A value that is not a plain model token (or starts with `-`) is ignored and never reaches argv. New `nunchi.py synth-model` prints the configured model; `bench.sh` adds `- synth backend/model: claude <model> (cli <claude --version>)` to its summary. `install-nunchi.sh` passes the variable through its re-exec and stamps it on the conflict-sweep line when set at install time, like `NUNCHI_SYNTH_ORDER`. Reading the resolved id from `--output-format json` `modelUsage` is left out: it would change how the answer is parsed.
