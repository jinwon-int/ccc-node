- **Skill promotion retries infrastructure-failed review and revise rounds on another node instead of leaving them for human judgment (#2435 S1, absorbs #2395 items 1-2).** A review or revise task that failed before producing any result is classified from the broker error text alone as `auth_expired`, `balance_exhausted`, `cli_incompatible`, `rate_limited` or `timeout`. The first such failure per head is consumed as `infra_failed` (ledger `a2a-verdict` / `a2a-revise-result` status) with a PR comment naming the class. A review head stays owed to the missing-dispatch sweep, which re-dispatches it on the next collect with the failed reviewer disqualified; the dispatch idempotency guard ignores the infra-failed round. A revise round is re-dispatched immediately with the findings from the failed task's own payload, excluding the failed node — an excluded author hands the round to a B2 substitute regardless of the age threshold. Infra-failed rounds do not count against the revise round limit, the daily cap, the one-dispatch-per-head guard or the lineage's one substitute. A second infrastructure failure on the same head falls back to the previous terminal `malformed` / `failed` record. Field cases (2026-10-07..20): Claude OAuth expiry on two reviewer nodes, a Claude Code 2.1.278 model incompatibility, and provider balance exhaustion on a second worker lane.
