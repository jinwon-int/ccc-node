The bridge owns distill in every mode (it injects `CCC_BRIDGE_DISTILL_MANAGED=1`, so the Claude distill hook stands down), but its local sink was only composed for `audience-scoped`; on `off`/`curated` every extraction completed and then sat as `local_sink_status=unroutable`, and `memory-facts.jsonl`/`resume.md` stopped advancing. A node-global route of `CodexDistillLocalSinkWorker` now writes route-free jobs into the unscoped state dir (`$CCC_STATE_DIR`, else `<claude-root>/state`) with the hook path's bounds and refreshes `ccc-memory-index.sh` against that state with the node's own Wiki/index policy; no audience nunchi feed is kicked (global nunchi keeps reading the journal via `ingest-cron.sh`).
