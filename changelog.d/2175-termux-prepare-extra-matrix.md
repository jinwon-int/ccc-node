- **`termux_prepare.py --extra matrix` installs the Matrix frontend extra inside the prepared job (#2175 B).** Nodes serving `CCC_CHANNEL=matrix` used to add `requirements-matrix.txt` to a prepared runtime by hand after the receipt was written. The extra is now installed after the core fresh-install/reinstall scenarios, constrained to the core runtime's own `pip freeze` so it can only add distributions; a second freeze must keep every core line (`extra_matrix_changed_core`), an import probe requires e2e-enabled `matrix-nio` with `olm`, `pip check` passes, and core readiness runs again. The receipt records `extras.matrix` (status, requirements hash, added distributions). python-olm is built against Termux's system libolm from a hash-pinned sdist with an exact-hash build script (the bundled C++ libolm no longer compiles with CMake 4 / clang 21), recorded under `extras.matrix.olm`. The extra stays unlocked by design.
