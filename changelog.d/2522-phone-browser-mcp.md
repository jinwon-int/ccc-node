- **New `phone-browser-mcp`: a phone's real Android Chrome as a stdio MCP browser (#2522).** `~/.claude/hooks/phone-browser-mcp.sh <ssh-host> [--mcp chrome-devtools|playwright] [-- extra args]` creates a per-session `adb forward tcp:0 localabstract:chrome_devtools_remote` with the phone's own adb (no local adb needed), opens a private SSH ControlMaster tunnel to a free local port, and runs the pinned `chrome-devtools-mcp@1.12.0 --browserUrl` (default, with `--no-usage-statistics --no-performance-crux`) or `@playwright/mcp@0.0.83 --cdp-endpoint`. Register with `claude mcp add -s user android-browser -- ~/.claude/hooks/phone-browser-mcp.sh <ssh-host>`. Requires Android USB debugging on (Chrome opens no DevTools socket with wireless debugging alone); when it is off the launcher exits 6 with instructions and never changes the setting. A missing socket with USB debugging on wakes the screen and foregrounds Chrome. Only this session's forward and tunnel are removed on exit/TERM/INT/HUP; every ssh runs with `-n` and all launcher output goes to stderr so stdout stays pure MCP. The screen must be on for screenshots (Chrome renders no frames while it is off); the launcher wakes it once, `PHONE_BROWSER_KEEP_AWAKE=<sec>` keeps waking it. CDP drives the phone's Chrome profile — prefer `new_page` `isolatedContext` (works on Android Chrome) for anything not needing its logins.
