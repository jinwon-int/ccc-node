- **A CI-red intake PR no longer waits forever (#2656).** A `dispatch_ci_not_green` skip now records `pr`, `head_sha` and `ci` (`failure` = the `skills` check completed red, `pending` = not done or unreadable) and is written once per `(pr, head, ci)` instead of every 15-minute retry (1,098 identical rows for three PRs in nine days); the first `failure` row sends one `SkillIntakeCiRed` push-spool notice. Known-red heads go last in the 3-slot redispatch window so they stop starving newer intakes, and the new `_sweep_ci_red_intakes` closes an open intake PR whose head has been red for `CCC_SKILL_PROMOTION_CI_RED_CLOSE_DAYS` (default 3, `0` off) after one more live check read — `a2a-intake-ci-red-closed` (`archived:ci-not-green`) plus the CLOSED state row. Validation failures are never bypassed; a reviewed, changed or already-closed (owner may reopen) head is left alone; pre-#2656 skip rows do not age a PR.
