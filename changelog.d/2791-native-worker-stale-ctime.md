- **Termux native worker: serving≠installed also sees a tar redeploy (#2791 2a).** `a2a_native_worker_stale_report` compares each process start with the later of the file's mtime and ctime, not the mtime alone. A tar redeploy keeps the build's mtime — on 2026-11-24 `dist/worker.js` kept `10:29:40` on both Termux nodes while its ctime was the deploy (~3.5 h later) — so a worker that kept serving old code after such a deploy would not have been reported. Still warn-only: nothing is restarted; a chmod/chown after start now also shows as changed. New test (mutation-checked): a worker.js with a 2000-01-01 mtime replaced after its process started is reported.
