- nunchi `ingest-cron.sh` no longer defaults to the Telegram journal only: without `CCC_BRIDGE_DISTILL_JOURNAL` it ingests every existing bridge distill journal under `$HOME` — `~/.ccc-matrix/distill-journal`, `~/.ccc-hande/distill-journal` and `~/.telegram_bot/distill-journal` (the locations `ccc_doctor.py` scans) — so nodes that retired Telegram stop silently ingesting nothing (#2350).
- The Telegram journal is skipped when the frontend list (`CCC_FRONTENDS`, else `~/.claude/frontends`) exists and does not name `telegram`; no list keeps the legacy behaviour. An explicit `CCC_BRIDGE_DISTILL_JOURNAL` still selects exactly one journal.
- Audience-scoped mode calls `claude-audience-feed.py` once with every selected journal: `--journal` is now repeatable (a single value still works), so each scope's distill-history is read once, rejection counts are not multiplied, and sidecar pruning keeps an old sidecar whose session has a pending job in any journal. The "no input source" warning now lists every location checked.
