- **Fleet work board: open issues and PRs, sorted by whose turn it is, rebuilt as one Wiki page every day (#2914).** `scripts/ccc-work-board.py` reads every non-archived repository of the organisation over the GitHub API (read-only), renders `pages/current/work-board.md` and submits it through `wiki-agent write-path`/`pr` — only when something besides the generation time changed. Issues are sorted by the newest `status:v1` marker on them (`waiting=owner|node|date|external`, optional `node`, `due`, one-line `next`); `scripts/ccc_issue_status.py set` posts one, and `gh-pr-flow` / `bridge-safe-detached-run` now say when to. The page carries titles, numbers, labels, dates and marker fields only — no comment bodies; issues opened outside the fleet appear by number only. `scripts/install-work-board-timer.sh` installs the daily 05:30 KST timer on the hub (dry-run by default). Details: `docs/work-board.md`.
