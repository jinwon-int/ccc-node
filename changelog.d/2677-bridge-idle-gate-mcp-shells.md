- `scripts/bridge-idle-gate.py` (#2677): an MCP server registered through a shell wrapper (`bash /usr/local/bin/wiki-agent mcp-serve`, `bash -c "npm exec chrome-devtools-mcp"`) is no longer counted as a tool command. It is a shell whose parent is the provider CLI, so the #2567 rule kept the gate `busy` for as long as the provider session lived, even with no turn running, and gated restarts were deferred indefinitely (nosuk/bangtong 2026-11-05). The exception covers only provider-parented shells without the shell-snapshot wrapper that run one simple command (no shell control characters) naming an MCP server (`mcp-serve`, `mcp-server[-*]`, `mcp-*`, `*-mcp`, `*_mcp`); snapshot-wrapped Bash-tool commands and background watchers such as `bash -c "sleep 600"` still count.
