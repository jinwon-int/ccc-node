- **Tool cheatsheet: repo-managed fleet notes (#2858).** `hooks/tools-cheatsheet.md` is seeded once per node and never overwritten, so guidance added to the template never reached an installed node. `load-tools.sh` now appends `hooks/lib/tools-fleet-notes.txt` — deployed by the hook-tree walk on every update — after the node's cheatsheet. The first note says where a node's own daily span summary is (`<state>/spans-rollup/YYYY-MM-DD.json`), which agents could already read but had no way to know about. `CCC_TOOLS_FLEET_NOTES=0` turns the block off; it is also left out when cheatsheet + notes would pass 9,500 bytes, so a long node cheatsheet is never pushed over the hook output cap. `ccc-doctor.sh` counts the notes in the `tools-cheatsheet.md` always-on row.
