- deps-lock: the weekly lock-pair bot PR is opened by the org-owned `jinwon-deps-bot` GitHub App instead of `GITHUB_TOKEN`. Since 2026-09-14 the repository setting "Allow GitHub Actions to create and approve pull requests" is off, so `gh pr create` failed four Mondays running and only orphan `deps/lock-pair-*` branches were left; the setting stays off because it would also let every workflow token approve PRs. The workflow mints a one-hour installation token (`actions/create-github-app-token` v3.2.0, `pull_requests: write` + `contents: read`, this repo only) and `scripts/ccc-deps-lock-pr.sh` uses it for PR list/create/edit/close only (`CCC_DEPS_LOCK_PR_GH_TOKEN`); pushes, dispatch and run approval keep `GITHUB_TOKEN` (now `pull-requests: read`), and superseded bot branches are deleted with `git push --delete` because the App cannot delete branches (#2276).
