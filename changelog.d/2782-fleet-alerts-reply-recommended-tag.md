- **Fleet alert replies accept a leading `(권장)` tag (#2782 follow-up).** Agents now mark the recommended option `1. (권장) …`, so an owner who echoes an agent's relayed alert choice sends `1. (권장) ok <id>` — which the strict `ok/hold <id>` parser rejected, leaving the alert unanswered until its re-notify chain ran out (nosuk `#cpl92e`, 2026-11-13). `fleet_alerts_reply.REPLY_RE` now allows exactly one `(권장)`/`(recommended)` tag right after the optional list marker (or at the start); a tag anywhere else, twice, or without a following space still rejects the line, and the parse stays a deterministic regex.
