- **Read-only span view on the hub (#2858 item 4).** `scripts/spans-view-collect.sh` reads each node's daily rollup summary (`spans-rollup/YYYY-MM-DD.json`) over a read-only stdin probe (`scripts/spans_view_probe.py`, the `fleet-matrix-watch.sh` shape with `fleet-ssh-reuse`), and `scripts/spans-view.py` turns the answers into static pages: `YYYY-MM-DD.html` (one section per node) and `index.html` (node × day, last 30 days). Every answer is size-capped, must carry schema `ccc.spans-rollup.v1` and the requested day, and is copied field by field into a bounded record — unknown keys are dropped, a wrong type rejects the answer. A node that did not answer is shown as 「미수집」 with the reason (`ssh 255` → UNREACHABLE, timeout `124` → UNVERIFIED, no file, schema mismatch, size cap); an idle day is 「활동 없음」. Pages carry no script and every value is escaped. The output folder is opened once and used only through that descriptor (no symlink, owner checked), so another local account that owns the web root cannot redirect a write or delete; `--date` may not be later than yesterday, and the 90-day window always counts back from yesterday. `scripts/install-spans-view-timer.sh` prints (dry-run) or installs (`--apply`) a 04:30 Asia/Seoul systemd timer on the hub; nothing is installed on other nodes and no raw span leaves a node.
- **fleet-html-report: same-folder link cells (#2858).** A cell may be `{"text": …, "href": "name.html"}`; only a bare same-folder `*.html` name is accepted, any other href (scheme, slash, query, fragment, leading dot) is a spec error.
