- **New `phone-adb` helper: fleet ADB to Android/Termux nodes without per-node key authorization (#2517).** `~/.claude/hooks/phone-adb.sh <ssh-host> <adb args…>` opens (and reuses, one per host) an SSH ControlMaster tunnel to the phone's own adb server (`127.0.0.1:5037`) and runs the local `adb -H 127.0.0.1 -P <port> -s 127.0.0.1:5555 …`, so the phone's already-authorized self-loop key is the only key in play — access equals SSH access, nothing new to approve on the phone and no private key to distribute. Nodes without a local `adb` fall back to running it on the phone over SSH (shell-style subcommands; push/pull/install refused with a hint). Refuses `kill-server`/`start-server`/bare `disconnect`/`reconnect` (they would act on the phone's shared server), adb global options (host/port/serial are managed; use `--serial`), and mismatched local/phone adb versions (a mismatched client asks the server to exit). `--status` / `--close`. Replaces direct `adb connect <phone>:5555`, whose unused authorizations Android revokes, leaving `unauthorized` links and a pending "Allow USB debugging?" dialog on the phone.
