Also documents that an enqueue made with the repository `GITHUB_TOKEN` starts no `merge_group` workflow runs, so the PR waits as `AWAITING_CHECKS` until the queue drops it (a2a-nexus#2501); diagnose with `gh run list --event merge_group` and re-enqueue as a user.
