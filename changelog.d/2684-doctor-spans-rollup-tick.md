Every non-`--dry-run` run now overwrites `$CCC_STATE_DIR/spans-rollup.status.json` (0600, mkstemp + `os.replace`; `schema`, `finished_at`, `ok`, fixed `result_code` `queued` / `already-queued` / `no-spans` / `sanitizer-unavailable` / `crashed`, `date`, `node`). The write is best-effort: a failure warns on stderr and never changes the exit code, and a crash is recorded before it re-raises. Only fixed tokens and numbers from the file are printed. New suite `scripts/ccc_doctor_spans_rollup_tick_test.py` (validate-harness); `scripts/spans_rollup_test.py` covers the receipt.
