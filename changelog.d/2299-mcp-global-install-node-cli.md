- mcp: stdio web MCP servers (searxng, context7, firecrawl) now launch from a global npm install as `node <abs cli>` on every platform, not only on Termux. `npx -y <pkg>` kept a resident `npm exec` wrapper plus an `sh -c` per server per session. Measured on a 4 GiB node: ~266 MiB per session (searxng 180→95, context7 212→103, firecrawl 205→132 MiB, same tool lists), about a quarter of the 1024 MiB session-guard limit (#2298). `claude/mcp-setup.sh` installs the package globally when missing; on Linux it falls back to `npx -y` with a notice when no global install is possible (Termux still skips). The bridge's curated web MCP (`bridge/core/web_mcp.py`) resolves the global install from `$PREFIX`, `npm_config_prefix` or the prefix of the `node` on PATH, and falls back to `npx -y` when the package is absent. To take effect on an existing node, install the packages globally (`npm install -g mcp-searxng firecrawl-mcp @upstash/context7-mcp`, or re-run `claude/mcp-setup.sh`) and start new sessions. Re-running the script does not upgrade global installs; use `npm install -g <pkg>@latest` (#2299).
