- **Memory probe reports MemPalace refresh duration and a `slow` flag (#2722 C).** A Termux sweep ran ~22.5 min/hour with 69% of `mempalace search` calls failing while the probe still said `ok`. `ccc_memory_probe.mempalace_refresh_probe()` (and so `ccc-memory-check.sh --json` `.mempalace.refresh`) now adds `duration_seconds` (`finished_at - started_at` of a finished record), `running_seconds` (time since `started_at` while `running`) — `null` when not applicable — and `slow` (span above `CCC_NUNCHI_MEMPALACE_REFRESH_SLOW_SEC`, default 600). Keys are additive: `status`, readiness reasons and existing fields are unchanged; alerting stays with #2659.
