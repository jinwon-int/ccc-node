- skill-autosave: `CCC_SKILL_AUTOSAVE_MAX_SESSIONS` is now documented as what it always was — a per-branch budget (claude/codex/piri/danso each count separately, so N enabled branches can draft N× per run). New opt-in `CCC_SKILL_AUTOSAVE_TOTAL_MAX_SESSIONS` caps the cross-branch sum (default 0 = no cap, unchanged behavior); a capped branch logs `<branch> budget-stop reason=total-max-sessions`, and the sweep summary always reports `total_drafted=` with both budget values (#1824).
