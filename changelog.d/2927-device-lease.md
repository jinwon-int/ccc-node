- **`scripts/device_lease.py`: screen lease for a shared phone (#2927).** Before changing a shared device's screen (tap, swipe, key, `am start`, CDP click), a node takes a lease kept on the device itself (`~/.ccc-node/device-lease.json`: node, session, purpose, expiry, default 15 min, max 2 h) with `device_lease.py --target <host> acquire --purpose …`, and releases it when done. Another node's live lease returns exit 3 with the holder (`--wait N` polls); an expired lease counts as free; only the holder may renew or release; a torn lease file fails closed (exit 5) instead of reading as free. `--target` runs the same file on the device over ssh (`python3 -`, every word shell-quoted), so adb-TCP users who leave no ssh trace still see and name themselves in the same record. Read-only capture needs no lease. Motivation: two Play release steps on daegyo were interrupted by another node's adb input (2026-11-26, 11-27). Checked on Termux (gongyung, temporary path): acquire 0 → other node 3 → release 0.
