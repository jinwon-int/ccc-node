- **`install-nunchi.sh` keeps a node's gotgan budget and interpreter across self-update (#2475).** `GOTGAN_RUN_BYTES` and `CCC_NUNCHI_GOTGAN_PYTHON` were read from the installer's environment only and never written to the install record, so a self-update replay (which runs the recorded argv, not the operator's env) re-rendered the `:27` gotgan line without them — a Termux node pinned to 32 MiB silently went back to the 64 MiB default. New flags `--gotgan-run-bytes N` (positive integer) and `--gotgan-python /abs/path` set the same values; the env stays the default, and whichever was used is materialized in the record. The `--target-user` re-exec now passes both through its `env -i` as well. Unset values leave the line and the record unchanged.
