- **The skills-intake review handler now gets the same hardening as the revise handler (#1460).** The reviewer runs as `timeout -k "$REVIEW_KILL_GRACE_SEC" "$REVIEW_TIMEOUT_SEC"`. The grace defaults to 30s. A malformed or zero timeout or grace is refused as node config (exit 1). The log tells a timeout (124) apart from a SIGKILL after the grace (137). The run is a background job plus `wait`, so a TERM/INT/HUP sent to the handler reaches the reviewer and the temp dir is still removed.
- **The review handler enforces the reviewer tool lock instead of only defaulting to it (#1460).** It applies the revise handler's rule. Accepted: `--disallowed-tools *` / `--disallowedTools *` (or `=*`), `--no-tools` (including the header's `-p --no-tools --model xai/grok-4.6` example), or the `danso-review-agent.sh` wrapper. A dropped or narrowed lock, a quoted `"*"`, an allow-list or a permission bypass fails closed with exit 1 before the agent starts. An unset `REVIEW_AGENT_ARGS` still defaults to `-p --disallowed-tools *`.
- **The review handler resolves the reviewer node id once (#1460).** The prompt bindings, `output.reviewer_node` and `validations[].nodeId` now share one value, in this order: `WORKER_ID`, `A2A_WORKER_ID`, `hostname -s`, `unknown`. Before, without either env var, the prompt named the host while the result said `unknown`.
- **The review handler's size caps are symmetric (#1460).** The packet's `skillFiles` are checked against the publisher's 16 files / 64 KiB per file / 256 KiB total before any reviewer run (exit 1). Raw reviewer stdout is capped at 1 MiB (a `HANDLER_FAIL` oversized verdict, exit 1, the handler's single failure code).
- **The skill pre-screen skips drafts over the 256 KiB total instead of failing on them (#1460).** `prescreen.py` capped file count and per-file size but not the total, so a large draft would now hit the review handler's input cap and count as a reviewer error. Three of those in a row stopped the run as `reviewer-down`. Such a draft is now skipped before the handler, recorded as `skipped.oversize` in the run summary, and left undecided for the human gate. It does not count toward the three-errors stop.
