- **New skill `code-graph` (stage 1, Python): a local static call/import graph for jinwon-int repos (#2707).** `skills/code-graph/scripts/code_graph.py` uses only the standard-library `ast` module (no third-party packages, no server). `build <repo>` writes one JSONL per commit under `~/.cache/ccc-code-graph/` (module/class/function nodes; imports/defines/calls edges, each with `path:line`), and `callers`, `callees`, `imports-of` and `impact` (reverse-dependency files, depth 2 by default) answer from it as a table or `--json`. `calls` edges are tagged `exact` only when lexical scope or an explicit import resolves to one definition; everything else is `name-match`. Builds are opt-in (`.ccc-code-graph.toml` or `--repo`), refused for an origin outside `github.com/jinwon-int/*`, and refused on a dirty tree unless `--worktree` (then the cache key carries a content hash). Files with syntax errors are skipped and listed. Stage 2 (tree-sitter languages) and the sourcebundle hook are separate.
