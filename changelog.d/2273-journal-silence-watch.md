- scripts: new `journal_silence_watch.py` pages when a systemd unit's journal stops showing an expected line (e.g. `POST /notification`) for `--max-silence-min`. A webhook receiver stays green on every server-side check while its sender — a phone automation app whose task queue hung — silently stops posting; a 2026-10-11 outage went unnoticed for ~16 hours that way. Change-based paging through a 0600 state file (`NEW` once, `STILL` every `--still-every-min`, `RECOVERED` once with the outage span), an unreadable journal is `UNVERIFIED` rather than silence, and only timestamps/counts are printed — never the matched journal text. Exit 1 is the page: run it as an agent-cron `command` task with `telegram-owner-on-failure` and `--failure-alert-after 0` (#2273).
