- scripts: `scripts/fleet-metrics/fleet_merge_metrics.py` measures the fleet's GitHub merge pipeline per repo over N days, read-only via `gh api`: merged PRs/day, PR cycle time, merge-queue wait (`ADDED_TO_MERGE_QUEUE` → merged), merge-group count and **effective batch size** (merged PRs ÷ speculative groups), group wall time, and workflow runs/minutes/failure rate by event. Writes `merge-metrics-<stamp>.{json,md}`; one repo's API failure is reported in its row and does not stop the others; `/actions/runs` 1,000-run cap is flagged. Offline unit tests in `fleet_merge_metrics_test.py`; operator doc `docs/fleet-merge-metrics.md`.
