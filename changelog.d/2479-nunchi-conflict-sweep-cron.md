- **`install-nunchi.sh --conflict-sweep` schedules the nunchi conflict sweep daily, opt-in per node (#2479).** The flag (or `CCC_NUNCHI_CONFLICT_SWEEP=1`) adds one managed line at 04:53 running `nunchi.py conflict-sweep --apply --since-days 2 --max-pairs 100` into `~/.nunchi/conflict-sweep.cron.log`. The sweep only sets `review=1` and writes its pair ledger, so the line always runs `--apply` and needs no separate APPLY approval. The flag is materialized in the install record so a self-update replay keeps the line, and a re-apply without it removes the line. The installer refuses before touching the crontab when the installed `nunchi.py` predates the subcommand, stamps `NUNCHI_SYNTH_ORDER` / `NUNCHI_PIRI` / `NUNCHI_PIRI_ARGS` on the line when they are set at install time, and reports `conflict_sweep_cron` in its status. A real-DB measurement on one node judged all 470 pairs of a 7-day window: 6 flagged, 5 correct, 1 ambiguous, 0 false positives, ~67 new pairs a day (~4 Haiku calls a night). Rollout starts with a 7-day canary on one node.
