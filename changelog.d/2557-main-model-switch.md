- **ops: `scripts/main-model-switch.py` is the canonical main-model switch (#2557).** It replaces the node-local `apply.sh` that left `ccc-hande-bridge.service` pointing at a retired Matrix env file (#2571). It finds every `ccc-*-bridge.service.d/` with a `zzzzzzzzzzzzzz-main-*.conf` drop-in (no hard-coded channels). For each referenced `/root/.config/ccc-main` env file it writes `<channel>-<slug>.env`, changing only `ANTHROPIC_MODEL`, `CLAUDE_CODE_EFFORT_LEVEL` and `CCC_MODEL_LABEL`, and repoints every drop-in that shared the old file, the hande clone of the Matrix drop-in included. It also updates `model` in Claude `settings*.json` and in claude-provider chats of the bridges' `sessions.json`. Every touched file is backed up with a path-only `manifest.json`. An old env file is retired only when `env-file-guard.py users` exits 0, a failing `env-file-guard.py check` rolls everything back, and `--rollback <dir>` undoes a switch. `--dry-run` previews; restarts are opt-in (`--restart`: idle-gated stop → re-apply that unit's `sessions.json` → start, so the bridge's shutdown write-back cannot undo the per-chat update, then `/proc/<pid>/environ` verified). Env contents are never printed. `docs/bridge-ops.md` gains a "Main model switch" runbook.
