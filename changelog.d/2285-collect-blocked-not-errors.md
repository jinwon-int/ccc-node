- skill-promotion: an exporter's `blocked` diagnostics (a triggerless legacy envelope it deliberately leaves in place, #2099) no longer fail the publisher collect. `_collect_envelopes` folded them into `errors`, so `ok` went false and the nightly line read `promotion-collect failed` on every run whose source rotation reached that outbox — seoseo alternated failed/ok on 2026-10-08..12 (gongmyoung-lane, 9 such envelopes) while the same runs published other sources normally, and one-envelope manual removals kept "fixing" it. The collect result now carries them in a separate `blocked` list; the sweep logs a shape-checked `promotion-collect-blocked count=N [source:name:code,…]` line and `ccc-doctor` warns (with the fix-or-quarantine action) while any remain. The publish-loop trigger check for an envelope an older exporter still served stays a real error (#2285).
