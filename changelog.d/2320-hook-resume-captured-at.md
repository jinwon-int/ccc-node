- **The Claude distill hook no longer lets a replayed old backlog overwrite a newer `resume.md` (#2320).** `local-memory-commit.py` now orders its resume write the same way the bridge sink does: when the current resume header carries a `captured_at` strictly later than this job's capture time (`CLAUDE_DISTILL_CAPTURED_AT`, the pending-journal enqueue time), the resume is kept and only the facts merge (`local-memory: resume kept reason=newer-capture`). A header-less current resume falls back to the #2309 file-mtime proxy. Equal capture times still write (the later commit wins, matching the sink). A run without a capture time (outside the pending journal) writes as before, since it has nothing to order by. The hook cannot import the sink at runtime, so it mirrors the sink's header parser; a bridge test asserts both read the same `captured_at` from shared fixtures.
