- **Installed A2A handler copies no longer drift silently behind the checkout (#2357).** `scripts/install-a2a-review-handler.sh` copies the skills-intake dispatcher and handlers to `/usr/local/sbin` (Termux / non-root: `~/a2a-broker-worker`), and nothing refreshed them, so reviewer/reviser nodes kept running 2026-09-10 handlers while their checkouts were current. `ccc-doctor` now has an `a2a-handlers` check that compares each installed copy's sha256 with the checkout (`정상` when current or not installed, `경고` naming the drifted/missing files and the reinstall command). `ccc-self-update.sh` refreshes existing drifted copies on a changed tick — never a fresh install, no rewrite (and no new backup) when current, verified after install, no worker restart; a destination the tick cannot write (non-root tick, root-owned `/usr/local/sbin`) is skipped with one log line and no notification, while doctor keeps warning and names the owning account. A failure is logged, warned and notified but does not roll back or fail the update. Opt out with `CCC_SELF_UPDATE_A2A_HANDLERS=0`.
- **The installer now fails closed and states when a restart is needed.** A failed backup or `install` used to be reported as installed with exit 0; it now exits 1. `--list` prints the handler set. The closing hint says a worker restart is needed only after changing the env wiring: the worker spawns the handler per task, so replacing the files takes effect on the next task.
