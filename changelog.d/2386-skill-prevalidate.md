- **New read-only skill pre-validator, `scripts/ccc-skill-validate.py` (#2386).** It checks every skill root (repo default `skills/`, `codex/skills/`, `piri/skills/`; node mode `--root ~/.claude/skills`, repeatable) for: frontmatter present and closed, `description:` present and non-empty, `name:` equal to the directory, description free of measurement words (`benchmark`/`evaluation`/`grader`/`rubric`/`score`; warning, error with `--strict`), core skills from `claude/skill-listing-core.txt` named literally in the always-on text (CLAUDE.md, tools-cheatsheet, output styles), SKILL.md `scripts/*.py|.sh` references that resolve (skill-anchored refs must exist; bare refs fall back to the repo root or `~/.claude`), bundled `*.py` that compile, and settings/hooks JSON `hooks` blocks with known events, a `type`, a non-empty `command` and a positive `timeout`. Findings carry `path:line`, output is sorted, `--json` emits one object, and `--autotrigger --dry-run` prints a suggested trigger line for each untriggered core skill (it never writes). `validate-harness.sh` runs it in the static phase with its tests; the core-trigger rule is a warning there because 12 of 16 repo-shipped core skills have no trigger line yet (`docs/skill-validate.md`).
