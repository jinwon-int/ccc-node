- **nunchi recall weighs recency by kind (#2885).** The state-aware re-rank behind `recall`, `dialectic` and `why --query` added the same recency term to every row, which pushed the fact that matched the query best out of rank 1 whenever newer, weaker matches surrounded it. An open row of a static kind (`preference`, `decision`, `constraint`, `procedure`) now gets a tenth of that term; state-like and legacy/unknown kinds and closed rows of any kind keep all of it, so newer state still beats stale state and a superseded decision still sinks below its replacement. Measured on a read-only copy of one node's fact store (59 questions written from stored facts, 12 rows): rank-1 hits 0.32 -> 0.36 for keyword and 0.37 -> 0.44 for natural-language questions (MRR 0.512 -> 0.531 and 0.587 -> 0.616); in each set 5 targets moved up, 8 moved down by one or two places, none was lost. STALE bench unchanged. `NUNCHI_RECENCY_BY_KIND=0` restores the previous ordering exactly. `claude/hooks/nunchi/recency-by-kind.test.sh` pins the behaviour on a synthetic fixture.
