The per-draft append in `skill-review.sh` ran `jq` without `-n`, so it read the hook's already-drained stdin and emitted nothing — the index stayed 0 bytes on every node since #183 (2026-06-26) and nothing read it, so nothing noticed. The append now uses `jq -n` (and records the provider), and a new `skill-review.sh reindex` / `ccc-skill-autosave.sh reindex` rebuilds the index atomically from the queue: one row per draft directory with the status taken from the approve/install/reject rename suffix and the prescreen verdict, plus `archived:<kind>` rows from the archive manifests; a previous non-empty index is kept as `index.jsonl.bak-<ts>`. The nightly sweep runs the rebuild after drafting so every node heals on its next run. First step of the lifecycle ledger work (#2283).
