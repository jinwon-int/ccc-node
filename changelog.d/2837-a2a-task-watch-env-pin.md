- **`scripts/a2a-task-watch.sh` (new, cron-safe, read-only; ccc-node#2837): the Termux-native A2A pin watcher now compares against the worker's own env file instead of hardcoded pilot values.** The untracked pilot copy (`~/.a2a/a2a-task-watch.sh`) expected `A2A_WORKER_THINKING=medium` and so logged `PIN DRIFT` every 5 minutes since 2026-09-29 (~15,600 lines per node) after the fleet moved to `high`, burying any real drift. The tracked script reads seven pin keys from `--env-file` and `/proc/<pid>/environ` and compares them key by exact value (keys the env file does not pin are skipped; an env file pinning none is `NOPIN`). A drift line names only the mismatched keys with expected/actual values, is logged when its signature changes and then at most hourly (`A2A_TASK_WATCH_REPEAT_SECS`), and the log rotates to `.1` past 1 MiB (`A2A_TASK_WATCH_MAX_BYTES`). Only the allowlisted pin keys are read or printed. The `TASK ACTIVITY` capture is unchanged. Pre-merge check on both Termux workers: the real env files give no drift (rc 0, worker pid found), and a deliberately wrong expected value is reported as one `DRIFT A2A_WORKER_THINKING expected=medium actual=high` line. Switching the nodes' cron entries to this script is a separate step after merge.
