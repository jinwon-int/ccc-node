- **fix(doctor): `distill snapshot refusals` only reads regular job files and labels danso journals apart (#2308).** A `*.json` FIFO in a distill journal hung `ccc-doctor` forever and symlinked entries were followed. The scan now skips any entry that is not a regular file (`is_file(follow_symlinks=False)`, matching the bridge journal's `O_NOFOLLOW` regular-file rule) and reads through a non-blocking `O_NOFOLLOW` descriptor, so an entry swapped after the scan is skipped too. The status row now names the journal (`ccc-matrix/danso`, `telegram_bot/danso`) so a danso refusal is no longer indistinguishable from a Claude one.
