- **agent-cron owner notifications keep container image references readable (#2624).** The long-token-run backstop masked `ghcr.io/<org>/<repo>`, so image drift/deploy alerts read `[REDACTED_CREDENTIAL]:1.2.3` and lost which image they were about. Image references now get the same narrow exemption as paths, GitHub links and `name=version` pairs: an exact registry host allowlist (`ghcr.io`, `docker.io`, `quay.io`, `registry.k8s.io`, `gcr.io`, `public.ecr.aws`), lowercase `[a-z0-9._-]` segments each under the 24-char run threshold, and the reference must end at its tag, digest or the run boundary. Other or look-alike hosts, over-long or uppercase/`+`/`=` segments, trailing blobs and `@sha256:` digests stay masked.
