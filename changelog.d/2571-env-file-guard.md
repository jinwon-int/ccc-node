- **ops: `scripts/env-file-guard.py` refuses retiring an EnvironmentFile a unit still references (#2571).** On gwakga a node-local model-switch moved `matrix-opus55-high.env` into `retired/` while `ccc-hande-bridge.service` (whose drop-ins `install-hande-bridge.sh` copies from Matrix) still required it, so its next restart failed and the bridge stayed down 14.7 h. `env-file-guard.py users <path>...` lists every loaded `ccc-*`/`native-relay-*` unit (system manager plus each `--user <name>` manager; `--unit-glob`, `--all`) whose EnvironmentFiles resolve to the path, tagged `required`/`optional`, and exits 1 if any remain; `check` exits 1 for units whose required EnvironmentFiles are missing. Paths only, never env contents; `--json` for scripts. `docs/bridge-ops.md` gains a "Retiring or replacing an EnvironmentFile" procedure.
