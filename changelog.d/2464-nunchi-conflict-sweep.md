- **`nunchi.py conflict-sweep` flags implicit state conflicts for review (#2464 제안 2).** It pairs each recent open fact with the older open facts of the same peer and kind, and asks the synthesis backend (Haiku) once per 20 pairs whether the newer fact makes the older one untrue. The write gates compare token overlap only and caught 0/400 STALE conflicts; on the 40-scenario fixture the sweep caught 32/40 with 4/80 false positives on distractor pairs. The sweep only sets `review=1` on the newer fact and records the pair in a new `conflict_sweep` ledger, so re-runs are idempotent and an owner clear stays cleared. It never closes, supersedes or deletes. The default is a dry run, `--apply` writes, and an unusable verdict writes nothing and exits 1. `review` names the older partner, and `judge-batch` counts that partner as a live sibling so the deterministic pass no longer auto-clears these flags. The sweep is not scheduled by cron.
